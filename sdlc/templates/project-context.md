# Project context template

Create these three local files on the first interaction with a project. Write them in the local language chosen for planning artifacts.

## architecture.md

- System purpose and major modules
- Runtime entry points and external integrations
- Data, authentication, authorization, tenancy, and deployment boundaries
- Existing repository instructions and verification commands
- Risks and unknowns

## back-end.md

- APIs, jobs, events, data stores, and service boundaries
- Error handling, observability, and test patterns
- Important dependencies and external systems
- Read/write constraints and performance-sensitive paths

## front-end.md

- Applications, routes, state/data flow, and API clients
- Design system components, tokens, typography, colors, spacing, and accessibility patterns
- Responsive behavior and existing test/visual-validation approach
- Missing design-system evidence or open decisions
