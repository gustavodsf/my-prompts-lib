# Shared SDLC configuration

Use [sdlc/SDLC.md](sdlc/SDLC.md) as the shared delivery workflow and [sdlc/error.md](sdlc/error.md) as its error catalog.

Use the commands and skills in this repository for project context, planning, evidence, QA, review, and authorized GitHub issue work. Keep task-generated Markdown outside the repository and do not commit it.

For interface work, identify and follow the target project's design system. For API validation, use visible terminal HTTP evidence. For UI/E2E validation, use a visible browser and capture sanitized visual evidence.
